# Smile Center: Cabinet de Ortodontie Dr. Camelia Szuhanek

Website premium, ultra-modern și complet responsiv realizat pentru **Smile Center: Cabinet de Ortodonție Dr. Camelia Szuhanek** din Timișoara. 

Aplicația este dezvoltată utilizând **Node.js (Express.js)** pe backend și **Vanilla CSS & JavaScript (ES6)** pe frontend pentru o performanță și viteză de încărcare remarcabile.

---

## ✨ Caracteristici Cheie
- 🦷 **Fundal Video Dinamic local**: Redare video 3D de înaltă tehnologie cu reconstrucția și segmentarea dinților (format WebM de doar 603 KB pentru o încărcare instantanee).
- 🌓 **Suport Dual-Theme (Light & Dark Mode)**: Modifică instantaneu tematica întregii pagini și a hărții interactive, salvând opțiunile în `LocalStorage`.
- 🗺️ **Hartă Interactivă Leaflet.js**: Integrată cu temele vizuale și customizată cu un marker pulsatoriu.
- 📱 **Design Fluid & Responsiv**: Optimizat mobile-first (de la telefoane compacte până la ecrane ultra-wide de desktop).
- 💬 **Recenzii Google Verificate**: Carousel interactiv care prezintă feedback-ul de 5 stele al pacienților mulțumiți din Timișoara.
- 🎚️ **Smile Slider Comparativ**: Widget interactiv glisabil Înainte/După bazat pe grafică vectorială curată (dinți înghesuiți vs perfect aliniați).
- 📅 **Formular AJAX de Programare**: Procesare securizată pe backend cu validări complete și modal de succes customizat.

---

## 🛠️ Tehnologii Utilizate
- **Backend**: Node.js, Express.js
- **Frontend**: HTML5, Vanilla CSS3 (Custom properties, grid, flexbox), JavaScript (ES6)
- **Biblioteci externe (via CDN)**:
  - [Leaflet.js](https://leafletjs.com/) (Hărți interactive)
  - [FontAwesome 6.4.0](https://fontawesome.com/) (Pictograme premium)
  - Google Fonts (Outfit & Inter)

## 🚀 Instalare și Rulare Locală

### Cerințe preliminare
- [Node.js](https://nodejs.org/) instalat pe sistemul dumneavoastră.

### Pași de pornire
1. Clonați sau descărcați acest depozit:
   ```bash
   git clone https://github.com/[username]/smile-center-web.git
   cd smile-center-web
   ```
2. Instalați dependențele necesare:
   ```bash
   npm install
   ```
3. Lansați serverul în modul de dezvoltare/producție:
   ```bash
   npm start
   ```
4. Deschideți browserul la adresa:
   👉 **[http://localhost:3000](http://localhost:3000)**
